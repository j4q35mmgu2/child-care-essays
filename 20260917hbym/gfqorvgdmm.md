# 济宁马拉松跑友健康指南——来自济宁市第一人民医院医护人员的贴心提醒

> 更新时间：2026-09-17 (UTC+8)

亲爱的马拉松跑友： 

欢迎参加济宁马拉松！作为济宁市第一人民医院的医护人员，我们深知您对比赛的热情，但更关心您的健康与安全。我们从专业角度为您整理参赛注意事项，助您科学完赛、远离损伤。  

一、赛前准备——健康是完赛的基础

1. 健康筛查不可少

赛前1周建议进行心电图、血压检测，尤其是有以下情况者：  

✓ 近期感冒/发热  

✓ 高血压、糖尿病等慢性病史  

✓ 既往运动中出现过胸痛、晕厥  

护理提醒：济宁市第一人民医院急诊科曾接诊因未筛查而诱发心绞痛的马拉松选手，请勿忽视潜在风险。  

2. 适应性训练要科学

赛前2周逐渐减量，最后3天以拉伸、慢跑为主。  

模拟比赛时段训练（如早晨7-9点），适应生物钟。  

二、比赛日——关键细节决定安全 

1. 出发前“三查”  

查装备：号码布固定于胸前（避免摩擦乳头），鞋带打“跑者结”防松散。  

查体温：晨起体温＞37.3℃需谨慎参赛。  

查药物：哮喘患者随身携带喷雾剂，糖尿病患者备好糖块。  

2. 赛中“四警惕”

警惕胸痛/压迫感：可能是心肌缺血信号，立即停止运动并求助医疗点。  

警惕头晕眼花：可能提示低血糖或脱水，及时补充含糖饮料。  

警惕肌肉抽搐：缓慢拉伸抽搐部位，补充盐丸或电解质水。  

警惕关节肿胀：如膝关节突发刺痛，避免强行继续奔跑。  

3. 补给站正确使用法 

饮水时捏扁杯口小口饮用，防呛咳。  

降温海绵先擦拭后颈、腋下，效果最佳。  

三、赛后恢复——专业护理建议

1. 终点站“三步处理法”

第一步：领取奖牌后立即披上保温毯，预防血管骤缩。  

第二步：缓慢行走15分钟，忌立即坐下或拉伸。  

第三步：少量多次饮用含糖电解质饮料（每小时不超过800ml）。  

2. 24小时黄金恢复期

冷水浴（10-15℃）或冰敷酸痛部位10分钟/次。  

睡前抬高下肢20分钟促进静脉回流。   

3. 这些症状速就医

✓ 持续头晕/呕吐  

✓ 尿量减少且颜色深红  

✓ 关节肿胀无法行走      

暖心提示： 

马拉松是意志的考验，更是对身体的尊重。当您经过医疗点时，我们的白衣天使将始终为您护航！
